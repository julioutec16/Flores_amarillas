COMO PERSONALIZAR TU SORPRESA

1. Abre index.html y cambia el mensaje por uno propio.
2. Coloca una canción MP3 en esta carpeta y llámala musica.mp3.
3. Si quieres cambiar la imagen, reemplaza fondo.png por otra imagen y conserva ese nombre.
4. Para publicarla gratis:
   - Crea una cuenta en GitHub.
   - Crea un repositorio nuevo, por ejemplo: sorpresa-girasoles.
   - Sube index.html, fondo.png y musica.mp3.
   - En Settings > Pages, activa GitHub Pages usando la rama main y la carpeta root (/).
   - GitHub te dará un enlace público para enviar por WhatsApp.

NOTA: Usa una canción que tengas derecho a compartir. Algunos navegadores bloquean la reproducción automática; por eso la página incluye controles de audio.
